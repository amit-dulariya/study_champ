## What I Built
**StudyChamp: The Ultimate Study Companion**
I built this application for a friend who is currently a student and struggles with context-switching between multiple productivity apps. They needed a unified solution to manage their focus time and study materials without getting distracted. 

StudyChamp solves this by combining four essential tools into one sleek, gamified dashboard:
1. **Pomodoro Timer**: For structured, focused study sessions with break intervals.
2. **Task Manager**: To track assignments (integrated directly with the Pomodoro timer so you can mark a task as "Active").
3. **Flashcard System**: For interactive memorization with a 3D flip effect.
4. **Quiz Builder**: To create and take custom quizzes for self-assessment.

By adding a gamified XP system, visual statistics tracking (via Chart.js), and celebratory confetti, it keeps studying engaging and keeps everything confined to a single browser tab.

## How I Built It
StudyChamp was built using **Vanilla HTML, CSS, and JavaScript** to ensure it remains lightweight, blazingly fast, and completely free of heavy build dependencies. 

I collaborated with the **Antigravity AI Agent** to rapid-prototype and architect the application. The agent assisted in:
- Designing the modern glassmorphism UI and responsive side-navigation layout.
- Writing the core vanilla JavaScript logic for the integrated Pomodoro and Task system.
- Implementing LocalStorage data persistence so no external backend was required.
- Integrating open-source libraries like `Chart.js` for the focus history dashboard and `Canvas-Confetti` for visual rewards.
